# 🎬 NoBarDi — Nonton Bareng Digital

A CloudStream 3 extension repository dikembangkan oleh **RomantiKode**.

Repository ini berisi extension CloudStream untuk berbagai sumber **Movie, TV Series, Anime, dan konten lainnya**, dengan fokus pada kompatibilitas, playback yang stabil, dan pengembangan provider yang terstruktur fokus provider Indonesia.

> Extension dapat berubah mengikuti perubahan pada website sumber. Situs yang berhenti bekerja akan diperbaiki atau diperbarui jika memungkinkan.

---

## 📋 Keperluan

Anda memerlukan **CloudStream 3** untuk menggunakan extension dari repository ini.

Dokumentasi CloudStream:

https://recloudstream.github.io/csdocs/

---

## 📥 Cara Pakai Repository

1. Buka **CloudStream**
2. Masuk ke **Settings**
3. Pilih **Extensions**
4. Pilih **Add Repository**
5. Masukkan URL repository extension
6. Tekan **Add**

Format repository CloudStream:

```text
https://raw.githubusercontent.com/RomantiKode/NoBarDi/builds/repo.json
```

Setelah repository ditambahkan, plugin yang tersedia akan muncul di menu **Extensions** dan dapat diperbarui melalui CloudStream.

## 🔄 Pembaruan

Website sumber dapat berubah kapan saja.

Akibatnya, sebuah extension yang sebelumnya bekerja dapat mengalami masalah seperti:

- Tidak dapat membuka detail
- Search tidak menemukan hasil
- Episode tidak muncul
- Player berubah
- Extractor tidak dapat menemukan media
- Domain sumber berpindah
- Metadata provider berubah

Extension akan diperbarui ketika perubahan tersebut dapat diidentifikasi dan diperbaiki.

## ⚠️ Ketersediaan

Tidak ada jaminan bahwa seluruh provider akan selalu tersedia.

Ketersediaan konten bergantung sepenuhnya pada website sumber dan layanan pihak ketiga yang digunakan oleh masing-masing extension.

---

## ⚖️ Disclaimer

Extension di repository ini bertindak sebagai client yang mengakses informasi dan media yang tersedia dari website sumber.

Repository ini:

- tidak menyimpan file video,
- tidak meng-host film atau serial,
- tidak meng-upload konten,
- dan tidak mengoperasikan server media yang digunakan oleh website sumber.

Konten dan stream tetap berasal dari website atau layanan pihak ketiga yang digunakan oleh masing-masing provider.

CloudStream dan pengembang CloudStream tidak berafiliasi dengan repository ini.

Pengguna bertanggung jawab untuk mematuhi hukum dan peraturan yang berlaku di wilayah masing-masing.

---

## 🛠️ Issues

Jika menemukan extension yang tidak bekerja, sertakan informasi sebanyak mungkin ketika menemukan kendala, misalnya:

- Nama extension
- Judul Movie / Series / Anime
- URL sumber jika tersedia
- Error yang muncul
- Apakah detail page dapat dibuka
- Apakah episode muncul
- Apakah video dapat diputar
- Versi extension
- Versi CloudStream

Informasi tersebut akan sangat membantu proses diagnosis.
